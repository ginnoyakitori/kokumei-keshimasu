ゲームルール（タップで開く）

盤面の全ての文字を消去してクリアを目指すパズルゲームです。

  • 消去条件: 盤面上の文字を、一直線（縦または横）に選択し、その文字列を有効なワードにすることで消去できます。
  • 選び方: 最初の文字から最後の文字まで指でなぞる（ドラッグ）か、1文字ずつタップします。最後に選んだ文字をもう一度タップすると取り消せます。
  • モード: 国名、首都名、ポケモン名の3種類で遊べます。
  • ワイルドカード: 文字「F」は任意のカタカナ一文字として使用可能です（Fを使って消したワードは図鑑に登録されません）。
  • 制限: 同じワードは2回以上使えません。
  • 重力: 文字を消去すると、その上の文字が下に落下します。
  • 問題選択: 問題一覧から好きな問題を選んで挑戦できます。
  • リセット: 消し方を間違えた場合、リセットボタンで最初の盤面に戻れます。
